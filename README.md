# Quick Dock — SillyTavern extension

เก็บปุ่มลอยหลายปุ่มให้เหลือ **ปุ่มเดียว** บนจอ แตะแล้วเปิดแผงเล็ก ๆ ที่มี

- **ช็อตคัท** — ผูกกับปุ่มไหนของ SillyTavern ก็ได้ (กดค้างที่ปุ่มนั้นครั้งเดียว) ถ้าปุ่มอยู่ในเมนูที่ปิดอยู่ จะกดเปิดเมนูให้ก่อนอัตโนมัติ
- **ถาดปุ่มลอย** — ย้ายปุ่มลอยของ extension อื่นเข้ามาเก็บในแผง ปุ่มยังทำงานเหมือนเดิมทุกอย่าง

ถ้าปุ่มในถาดแจ้งว่ามีปัญหา (เช่น Chat Auto Backup ขึ้น `Attention!`) ปุ่มหลักจะมีจุดแดงกระพริบ แม้ปิดแผงอยู่ก็เห็น

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

| ทำอะไร | วิธี |
|---|---|
| เปิด/ปิดแผง | แตะปุ่มหลัก |
| ย้ายปุ่มหลัก | ลาก — ปล่อยแล้วดูดติดขอบจอ |
| เพิ่มช็อตคัท | แผง → **+ ช็อตคัท** → เปิดเมนูไปหาปุ่มได้ตามปกติ → **กดค้าง ~0.5 วิ** ที่ปุ่มจนขึ้นกรอบส้ม → ยกนิ้ว = บันทึกทันที แผงจะเปิดให้แก้ชื่อ/ไอคอนต่อ |
| เก็บปุ่มลอย | แผง → **ปุ่มลอย** → กดค้างที่ปุ่มลอยของ extension นั้นจนขึ้นกรอบส้ม → ยกนิ้ว = ย้ายเข้า dock ทันที หรือไปที่ตั้งค่า → **ค้นหาปุ่มลอย** แล้วกดเก็บทีละปุ่ม |
| ยกเลิกโหมดเลือกปุ่ม | แตะปุ่มหลัก ⚡ (หรือ ✕ บนแถบคำแนะนำ) |
| แก้ชื่อ / ไอคอน / ลำดับ / ลบ | แผง → ✏️ → แตะรายการ |
| เอาปุ่มลอยกลับไปลอยบนจอ | โหมดแก้ไข → แตะปุ่มนั้น → **คืนหน้าจอ** |

- ไอคอนใช้ชื่อคลาส Font Awesome 6 เช่น `fa-solid fa-book` (ค้นได้ที่ fontawesome.com/icons ใช้ได้เฉพาะไอคอนฟรี)
- ถ้าแถบ "กดค้างที่ปุ่ม…" บังปุ่มที่ต้องการ กด ⇅ เพื่อย้ายแถบไปด้านล่าง
- ปิด Quick Dock ในตั้งค่า → ปุ่มลอยทุกตัวกลับไปอยู่ที่เดิม

## ข้อจำกัด

- ช็อตคัทจำปุ่มด้วย CSS selector ถ้า SillyTavern หรือ extension เปลี่ยนโครงสร้างหน้า ช็อตคัทอาจหาปุ่มไม่เจอ ให้ผูกใหม่ (✏️ → แตะรายการ → 🎯)
- ปุ่มลอยที่ไม่มี id หรือ class ที่ไม่ซ้ำ อาจหาไม่เจอหลังรีโหลด (จะมีคำเตือนตอนเก็บ)
