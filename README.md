# Quick Dock — SillyTavern extension

เก็บปุ่มลอยหลายปุ่มให้เหลือ **ปุ่มเดียว** บนจอ แตะแล้วจะเห็น

- **ช็อตคัท** กางเป็นวงโค้งรอบปุ่มหลัก อยู่ในระยะนิ้วโป้งเวลาถือมือถือมือเดียว
  - สำเร็จรูป: **บนสุด** (ข้อความแรกของแชท) · **ล่าสุด** (ต้นข้อความล่าสุด) · **บอทตอบ** (ต้นข้อความล่าสุดที่บอทตอบ)
  - หรือผูกกับปุ่มไหนของ SillyTavern ก็ได้ (กดค้างที่ปุ่มนั้นครั้งเดียว) ถ้าปุ่มอยู่ในเมนูที่ปิดอยู่ จะเปิดเมนูให้ก่อนอัตโนมัติ
- **การ์ดถาด** — ปุ่มลอยของ extension อื่นย้ายมาเก็บตรงนี้ ยังทำงานเหมือนเดิมทุกอย่าง

ถ้าปุ่มในถาดแจ้งว่ามีปัญหา (เช่น Chat Auto Backup ขึ้น `Attention!`) ปุ่มหลักจะมีจุดแดงกระพริบ แม้ปิดแผงอยู่ก็เห็น

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

## ใช้งาน

| ทำอะไร | วิธี |
|---|---|
| เปิด/ปิด | แตะปุ่มหลัก |
| ย้ายปุ่มหลัก | ลาก — ปล่อยแล้วดูดติดขอบจอ · ถือมือขวาให้วางขอบขวาค่อนล่าง ถือมือซ้ายวางขอบซ้าย |
| เปลี่ยนไอคอนปุ่มหลัก | **กดค้างที่ปุ่มหลัก** → เลือกจากตาราง (มีทั้งอีโมจิและไอคอน) พิมพ์อีโมจิเอง หรือกด 🖼 ใช้รูปภาพ |
| เพิ่มช็อตคัท | การ์ด → **+ ช็อตคัท** → เลือกแบบสำเร็จรูป หรือ **เลือกปุ่มบนจอ** → เปิดเมนูไปหาปุ่มได้ตามปกติ → กดค้าง ~0.5 วิ จนขึ้นกรอบส้ม → ยกนิ้ว = บันทึก |
| เก็บปุ่มลอย | การ์ด → **ปุ่มลอย** → กดค้างที่ปุ่มลอยจนขึ้นกรอบส้ม → ยกนิ้ว = ย้ายเข้า dock หรือไปที่ตั้งค่า → **ค้นหาปุ่มลอย** |
| ยกเลิกโหมดเลือกปุ่ม | แตะปุ่มหลัก (หรือ ✕ บนแถบคำแนะนำ) |
| แก้ชื่อ / ไอคอน / ลำดับ / ลบ | การ์ด → ✏️ → แตะรายการ · ช็อตคัทแรก ๆ อยู่บนสุดของวง |
| เอาปุ่มลอยกลับไปลอยบนจอ | โหมดแก้ไข → แตะปุ่มนั้น → **คืนหน้าจอ** |
| ปุ่มลอยในถาดว่างเปล่า / กดไม่ได้ | โหมดแก้ไข → แตะปุ่มนั้น → **ใช้ไอคอนแทน** — ปุ่มจริงจะถูกซ่อนไว้ที่เดิม แล้วมีไอคอนในการ์ดที่กดแทนให้ (เปลี่ยนไอคอนได้) · Quick Dock จะสลับให้เองถ้าเห็นว่าปุ่มไม่แสดงอะไรใน dock |

- วงโค้งกางได้ไกลสุดราว 210px จากปุ่มหลัก (ระยะนิ้วโป้ง) ที่เหลือจะไปอยู่ในการ์ด · ปิดชื่อใต้ปุ่มหรือย่อปุ่มจะใส่ในวงได้มากขึ้น

## ปรับหน้าตา (ตั้งค่า → Quick Dock → หน้าตา)

กด **ดูตัวอย่าง** เพื่อเปิด dock ค้างไว้ แล้วปรับได้สด ๆ

| ตัวเลือก | ค่าที่เลือกได้ |
|---|---|
| ชื่อใต้ปุ่มช็อตคัท | แสดง · ไม่แสดง · แสดงเฉพาะตอนแก้ไข |
| ขนาดปุ่มช็อตคัท / ขนาดไอคอน | 30–80 px / 25–75% ของปุ่ม (ไอคอนปุ่มหลักใช้สัดส่วนเดียวกัน) |
| สีไอคอน · สีพื้นปุ่ม · สีขอบ · สีเน้น | ดึงจากธีม SillyTavern (Main Text, Italics, Underline, Quote, UI Background, Chat Background, UI Border, Shadow) หรือ **กำหนดเอง** |
| ความทึบพื้นปุ่ม · ความทึบปุ่มหลักตอนปิด | 0–100% · 15–100% (ใช้แค่สีของธีม ไม่เอาความโปร่งใสของธีมมาคูณซ้ำ · ปุ่มหลักจะทึบเต็มเมื่อเปิดอยู่หรือมีจุดแจ้งเตือน) |
| เอฟเฟกต์ตอนชี้/กด | วงแหวน · ขอบเปลี่ยนสี · พื้นอมสีเน้น · ขยาย · ยุบ · ลอยขึ้น · ไม่มี |
| **ชุดสำเร็จรูป** | คลาสสิก · มินิมอล · แก้วใส · ลูกอมมันวาว · ไล่เฉดสี · นีออน · ปุ่มนูน · ใบไม้ · แสตมป์ — เลือกแล้วปรับต่อเองได้ (ไม่เปลี่ยนสีที่ตั้งไว้ ยกเว้นนีออนที่ให้ขอบใช้สีเน้น) |
| รูปทรงปุ่ม | วงกลม · สี่เหลี่ยมมนมาก · สี่เหลี่ยมมน · สี่เหลี่ยม · ใบไม้ · หยดน้ำ |
| ลายพื้นปุ่ม | เรียบ · ไล่เฉดสี (เลือกสีไล่เฉดได้) · มันวาว · แก้วใส · นูน 3 มิติ · บุ๋มลง |
| ขอบปุ่ม | หนา 0–4 px · เส้นทึบ · เส้นประ · จุดไข่ปลา · เส้นคู่ |
| ไอคอนที่เป็นรูปภาพ | เต็มปุ่ม (ตัดตามรูปทรงปุ่ม) · ขนาดเท่าไอคอน (เหมาะกับ PNG พื้นใส) |
| เรืองแสงรอบปุ่ม / เอฟเฟกต์ไอคอน | ไม่มี · อ่อน ๆ · เข้ม (ใช้สีเน้น) / เงาไอคอน · ไอคอนเรืองแสง |
| เงาใต้ปุ่ม / เบลอพื้นหลัง | เบลอปิดไว้เป็นค่าเริ่มต้นเพราะกิน GPU มากที่สุด |
| **ถาด dock** (ปุ่มลอย + แถบล่าง) | สีตัวอักษร · สีพื้น · สีขอบ · ความทึบพื้นถาด 0–100% · เงา · เบลอ แยกจากปุ่มช็อตคัท |

รูปทรง ลายพื้น ขอบ และเรืองแสง ใช้กับปุ่มหลักและช็อตคัทในวงโค้ง (เอฟเฟกต์ไอคอนใช้กับแผงตารางด้วย) · ทั้งหมดเป็นภาพนิ่ง ไม่มีแอนิเมชัน

เอฟเฟกต์ทุกแบบเปลี่ยนแค่สี เส้นขอบ หรือขนาดของตัวปุ่มด้านใน ไม่มีเบลอหรือเงาเคลื่อนไหว จึงกิน GPU น้อย
- ชอบแบบแผงตารางมากกว่า: ตั้งค่า → รูปแบบช็อตคัท → แผงตาราง
- ไอคอนพิมพ์เองได้ทั้งอีโมจิ และชื่อคลาส Font Awesome 6 เช่น `fa-solid fa-book` (ไอคอนฟรีเท่านั้น)
- **ใช้รูปภาพเป็นไอคอน** ได้ทุกปุ่ม (ปุ่มหลัก ช็อตคัท ปุ่มลอยแบบใช้ไอคอนแทน): กด 🖼 แล้วเลือกรูปจากเครื่อง หรือวางลิงก์รูป (`https://…`) ลงในช่องไอคอน · รูปใหญ่จะถูกย่อเหลือ 180px ก่อนเก็บ GIF เก็บตามเดิมได้ถึง 300 KB
- ปิด Quick Dock ในตั้งค่า → ปุ่มลอยทุกตัวกลับไปอยู่ที่เดิม

## ข้อจำกัด

- ช็อตคัทที่ผูกกับปุ่มจำด้วย CSS selector ถ้า SillyTavern หรือ extension เปลี่ยนโครงสร้างหน้า อาจหาปุ่มไม่เจอ ให้ผูกใหม่ (✏️ → แตะรายการ → 🎯)
- ปุ่มลอยที่ไม่มี id หรือ class ที่ไม่ซ้ำ อาจหาไม่เจอหลังรีโหลด (จะมีคำเตือนตอนเก็บ)
- ปุ่มในโหมด **ใช้ไอคอนแทน** ถ้ากดแล้วเปิดหน้าต่างที่ติดกับตัวปุ่มเอง หน้าต่างนั้นจะมองไม่เห็นไปด้วย และปุ่มที่เช็กว่าเป็นการกดจากนิ้วจริงเท่านั้นจะไม่ตอบสนอง
- **บนสุด** ในแชทยาวที่ยังไม่ได้โหลดข้อความเก่า จะใช้ `/chat-jump 0` ของ SillyTavern ซึ่งโหลดข้อความเก่าทั้งหมดก่อน แชทยาวมากอาจช้าสักครู่
